# Data Engineering Fundamentals

### A 10-Session Program for Analysts Ready to Build Pipelines

---

## The Opportunity

Data engineering is one of the fastest-growing roles in tech. Companies need people who can build the systems that power dashboards, ML models, and business decisions.

**The gap is real:**

- You know SQL and Excel
- You can build reports and dashboards
- But you don't know how to build the pipelines that feed them

**This program bridges that gap.**

In 10 hands-on sessions, you'll go from writing SELECT statements to building production-grade data pipelines — with the tools companies actually use.

## What Makes This Different

### Hands-On From Day One
Every session includes exercises you run on your own machine. No passive video watching — you write real code with real tools.

### One Consistent Dataset
All 10 sessions use banking transaction data. Concepts build on each other because the context stays the same. By Session 10, you'll know this dataset inside and out.

### Free & Open Tools
SQLite, Docker, Python, dbt, free-tier cloud accounts. No expensive software licenses or proprietary platforms.

### Built by Practitioners
This program was created by engineers who build data pipelines professionally — not academics who lecture about them.
