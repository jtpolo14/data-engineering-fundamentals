# Data Engineering Fundamentals: From Analyst to Data Engineer

A 10-session program designed for analysts who are ready to build the pipelines they've been querying. You already know Excel and basic SQL — this program takes you the rest of the way.


---

## Program Overview

This program bridges the gap between data analyst and data engineer. Through 10 hands-on sessions, you'll go from writing SELECT statements to building production-grade data pipelines with SQL, Python, Apache Airflow, dbt, and cloud platforms.

Every session uses **real-world banking transaction data** so concepts build on each other from start to finish.

---

## Prerequisites

Before starting this program, you should have:

- Working knowledge of Excel (pivot tables, VLOOKUP, basic formulas)
- Basic SQL experience (SELECT, WHERE, JOIN, GROUP BY)
- Curiosity about how data gets from source systems to dashboards

**New to Python?** Complete our [Python Fundamentals course](../section1-foundations/lecture01/README.md) first — it's free and uses the same banking data theme.

## Expected Outcomes

By completing this program, you will be able to:

- Write production-grade SQL with window functions, CTEs, and optimization
- Build and schedule data pipelines with Apache Airflow
- Design dimensional data models (star schema, SCDs)
- Implement ETL/ELT pipelines in Python
- Work with cloud data platforms (S3, Snowflake/BigQuery)
- Ensure data quality with automated testing
- Transform warehouse data with dbt
- Architect and build an end-to-end data pipeline

These skills align with **Junior/Mid-Level Data Engineer** roles.
